# Sitio corporativo de Mizo

Sitio estático de Mizo: ingeniería e instalación de sonido, videoproyección, cámaras de seguridad y soporte TI en Chile.

## Stack

- Astro 5 (SSG)
- Tailwind CSS
- Sitemap XML automático

## Comandos

```sh
npm install
npm run dev
npm run build
npm run preview
```

Producción: `https://mizo.cl`
